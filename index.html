FUNDAMENTO MATEMÁTICO

¿Qué es el conjunto de Mandelbrot?

Se define a partir de z₀ = 0 y zₙ₊₁ = zₙ² + c. Si alguna iteración supera |zₙ| = 2, el punto c no pertenece al conjunto. No detectar un escape en un número finito de iteraciones no demuestra pertenencia.
